Usage & data

使用與資料說明

建議使用 Telegram Desktop 匯出。這個頁面需要的是 result.json，不是純文字或 HTML。

Step 1

開啟聊天右上角選單

進入要分析的單一對話，打開右上角的 More 選單，選擇 Export chat history。

Step 2

格式選 JSON 後匯出

在匯出視窗把格式設成 JSON。匯出完成後，把資料夾裡的 result.json 拖進這個頁面即可。

Local-only workflow

使用說明

請在 Telegram Desktop 將單一對話匯出為 JSON，再把 result.json 匯入本頁。分析會在您的瀏覽器與瀏覽器 Web Worker 中完成，不會傳送聊天內容到 Cloudflare 或第三方服務。
