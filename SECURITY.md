# Security Policy

TG Chat Footprint is designed so Telegram chat exports stay in the user's browser.

## Reporting Security Issues

Please use GitHub Security Advisories to report vulnerabilities privately. Do not include private Telegram exports, real chat screenshots, access tokens, phone numbers, Telegram IDs, or other sensitive data in public issues.

## Reproduction Guidance

- Provide the smallest synthetic `result.json` snippet needed to reproduce the problem.
- Replace names, IDs, phone numbers, links, and message text with fake data.
- Do not upload real chat archives or screenshots.

## Out of Scope

Please do not report issues that require sending real private chat data to reproduce. Create a synthetic reproduction instead.
